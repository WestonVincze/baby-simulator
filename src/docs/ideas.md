## Gamification

Concept: "Babysitter Simulator"
- user is a babysitter tasked with keeping the baby entertained for a set time
- currency is rewarded and can be used between "jobs" to purchase new items or upgrades
  - buy new toys
  - repair toys
  - upgrade toys
  - upgrade playmat or toybox
  - buy abilities
  - buy single use items (candy)
- a frustrated baby could destroy a toy, rendering it useless
- bonus currency could be rewarded for positive impacts
  - education
  - training motor skills
- playmat could have items that interest the baby that could get damaged or hurt the baby
  - adds an extra difficulty layer as the user would need to keep baby entertained and away from obstacles
  - reduced rewards if an object is broken
  - could be interacted with by user, but risk breakage (much greater scope)
- maybe some toys need space to be played with
- character creator
