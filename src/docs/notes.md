## Balancing Aversions and Preferences

### How Aversions Work

- aversion builds on all attributes of a toy as baby plays with that toy
- aversion to an attribute depreciates over time if baby is not playing with a toy containing that attribute

### How Preferences Work

- preferences are randomized and slowly change over time
  - options:
    - a fixed value is distributed across multiple attributes (e.g. if total preference boost is 5 then 5 attributes could have a preference value of 1 or 10 could have a preference value of 0.5)
    - up to x attributes have preference scores randomized between set ranges (e.g. 0.1 and 0.4, 0.5 and 0.7, and 0.8 to 1, etc)
- aversion for preferred properties builds up more slowly
- baby may desire a toy with preferred attributes even if averse to its properties
